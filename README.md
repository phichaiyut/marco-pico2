# Macro Mymakers

มาโครพิมพ์คำสั่ง `fline(...)` อัตโนมัติด้วยคีย์ลัด (Windows + Python)

## วิธีใช้
1. ดับเบิลคลิก `run_macro.bat` (ติดตั้งไลบรารี `keyboard` ให้อัตโนมัติถ้ายังไม่มี) หรือรัน `python macro.py`
2. คลิกตรงที่ต้องการพิมพ์ แล้วกดคีย์ลัด
3. กด **Ctrl+Shift+Q** เพื่อปิดโปรแกรม

| คีย์ลัด | ข้อความที่พิมพ์ |
|---|---|
| Ctrl+Shift+1 | `fline(85, 85, 0.75, "a0", 'f', 'l', 80, "a2", 1);` |
| Ctrl+Shift+2 | `fline(85, 85, 0.75, "a7", 'f', 'r', 80, "a5", 1);` |
| Ctrl+Shift+3 | `fline(50, 50, 0.75, "a0", 'c', 'l', 70, "a1", 10);` |
| Ctrl+Shift+4 | `fline(50, 50, 0.75, "a7", 'c', 'r', 70, "a6", 10);` |
| Ctrl+Shift+5 | `fline(20, 20, 0.75, "a7", 'f', 's', 80, "a5", 10);` |
| Ctrl+Shift+6 | `fline(85, 85, 0.85, "a7", 'f', 'p', 80, "a5", 0);` |

แก้ค่าได้ที่รายการ `MACROS` ใน `macro.py`

## หมายเหตุ
- ถ้ากดแล้วไม่พิมพ์ ให้รัน `run_macro.bat` แบบ Run as administrator
- สลับแป้นพิมพ์เป็นภาษาอังกฤษก่อนกดคีย์ลัด
